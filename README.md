# PALINDROM CAPTIONS – web / iPhone

Slovenské AI titulky k videám (prepis reči cez Groq Whisper). Video zostáva v zariadení, do Groq sa posiela iba zvuk.
Groq API kľúč sa ukladá len v prehliadači používateľa (nie je súčasťou tohto repozitára).

Na iPhone: otvor stránku v Safari → Zdieľať → Pridať na plochu.
